# Android System Lab

A long-term personal lab for learning, experimenting with, and understanding the Android system stack.

The goal of this repository is to turn Android Framework knowledge into reproducible experiments, debugging cases, and practical system-level understanding.

## Focus

Current areas of interest:

- Android Framework
- AMS / ATMS
- WMS
- Input
- SurfaceFlinger
- HWC / HAL
- Perfetto & System Debugging
- Android Automotive / AAOS
- Native / Linux

More experiments and notes will be added gradually.

## Repository Structure

The structure will evolve over time.

Notes

This repository contains only personal experiments, public AOSP-related research, and sanitized technical notes.

No proprietary source code or confidential project information will be included.
